## Ominaisuudet

- **(TUI):** Selkeä ja näppäimistöllä navigoitava käyttöliittymä, joka toimii suoraan Windowsin komentokehotteessa / päätteessä.
- **Excel-integraatio:** Yhdistää automaattisesti tällä hetkellä aktiivisena olevaan Excel-työkirjaan.
- **Koodihaku:** Skannaa kaikki sarakkeet löytääkseen vastaavan koodin ja päivittää koko rivin.
- **Värin valinta:** Valitse käytettävä väri valmiista väripaletista.
- **Reaaliaikainen lokitus:** Näe livenä loki kaikista toiminnoista, mukaan lukien onnistuneet muutokset, ohitetut kohteet (jotka olivat jo oikean värisiä) sekä koodit, joita ei löytynyt.

## Käyttöohje

Helpoin tapa käyttää sovellusta on ladata valmiiksi käännetty suoritettava tiedosto (exe).

1. Avaa Excel-taulukko, jota haluat muokata. **Tärkeää:** Tiedoston täytyy olla aktiivisena eikä se saa olla "Suojatussa näkymässä" (Protected View), jotta yhteys muodostuu.
2. Suorita ladattu `muutavihreeks.exe`-tiedosto.
3. Sovellus näyttää yhteyden tilan Exceliin.
4. Valitse haluamasi väri listalta nuolinäppäimillä.
5. Kursori on aktiivisena syötekentässä. Aloita koodien skannaus (tai kirjoittaminen) ja paina `Enter` jokaisen koodin jälkeen.
