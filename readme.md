## Features

- **Terminal User Interface:** A clean, keyboard-navigable interface that runs directly in your Windows terminal.
- **Live Excel Integration:** Automatically connects to the currently active Excel workbook.
- **Fast Code Lookup:** Scans column 'C' for a matching code and updates the entire row.
- **Color Selection:** Choose from a predefined palette of colors to apply.
- **Real-time Logging:** View a live log of all operations, including successful changes, skipped items (already the correct color), and codes not found.

## How to Use

The easiest way to use the application is by downloading the pre-compiled executable.


1.  Open the target Excel spreadsheet you wish to modify. **Important:** The file must be active and not in "Protected View" for the connection to succeed.
2.  Run the downloaded `muutavihreeks.exe` file.
3.  The application will show its connection status to Excel.
4.  Use the arrow keys to select your desired color from the list.
5.  The cursor will be active in the input box. Start scanning codes (or typing them) and press `Enter` after each one.
